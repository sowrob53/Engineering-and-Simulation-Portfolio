# M.Sc. Mechanics Portfolio: Computational Engineering & Simulation

Welcome to my technical repository. This master portfolio is curated to highlight my projects in Advanced Finite Element Analysis (FEA), continuum mechanics, and numerical engineering methods, aligned with the computational curriculum at TU Darmstadt.

## 🛠️ Portfolio Table of Contents

### 1. Concrete Structures & Damage Mechanics (`/csdc`)
* **Project Folder:** [csdc](./csdc)
* **Objective:** Simulation of stress distribution and cracking in concrete structures.
* **Key Files:** Contains comprehensive model setups, batch files, and automated evaluation metrics stored in optimized `.zip` archives.
* **Keywords:** Continuum Mechanics, Fracture Mechanics, Concrete Damaged Plasticity (CDP).

### 2. Advanced Nonlinear Finite Element Methods (Upcoming)

* **Keywords:** Large Deformation, Contact Mechanics, ABAQUS/Explicit.

### 3. Numerical Methods & Scientific Computing (Upcoming)
* **Objective:** MATLAB/Python scripting for automated data filtering and post-processing of FEA output.
